## 二、国内上线：版号与合规（硬门槛）

> 以下为材料清单与流程说明，不构成法律意见；正式送审前请委托有出版经验的代理。

### 1. 版号（网络游戏出版服务号）
- 必经路径：**出版社**（游戏类出版资质）→ 省级出版行政主管部门 → **国家新闻出版署** 审批。
- 核心材料：
  1. 游戏内容自审报告（无违规内容：政治、暴力、赌博、意识形态风险自查）；
  2. 运营单位《网络文化经营许可证》、ICP 备案；
  3. 出版社选题批复 + 出版合同；
  4. 游戏说明书、演示视频（通常 5–10 分钟实机）、防沉迷系统说明；
  5. 计算机软件著作权登记证书（软著，越早办越好，周期约 1–2 个月）；
  6. 承诺书（不换皮/不私服/不作弊的运营承诺）。
- 时间预期：材料齐备后 **4–8 个月**（视政策松紧）；期间游戏**不得以任何形式收费运营**（可限量技术测试）。
- 本工程对应准备：防沉迷框架已就位（见第 3 节）；内容自审无内购/无社交敏感系统，风险面小。

### 2. 实名认证与防沉迷（强制）
- 所有国内运营游戏必须接入**国家新闻出版署网络游戏未成年人家长监护工程/实名认证系统**（现行为官方统一身份验证接口）。
- 工程现状：`PlaytimeGuard.VerifyMinor()` 已留接入缝，届时替换为官方 SDK 调用即可；限时/提示/展示层无需改动。
- 规则要点：未成年人仅可在周五、周六、周日和法定节假日 20:00–21:00 游戏，每日累计 1 小时；
  适龄提示（如 12+）须在开始界面展示。**注意：当前框架版不限时段只限总时长，正式版必须补齐时段规则。**

### 3. 适龄提示与内容标识
- 开始界面需展示《健康游戏忠告》国标三行（已实现于合规门）与适龄提示（建议按内容自评定级，本作为 Q 版像素风低暴力，预计 12+）。
- 商城/下载页须同规格展示。

## 三、商业化设计（建议）

**主推买断制（Premium）**：肉鸽幸存者品类以 Steam/Epic 买断 + 免费大型更新最健康，
也最契合当前工程形态（无账号体系、无服务端经济系统）。

| 项目 | 建议 | 说明 |
| --- | --- | --- |
| 本体定价 | Steam 国区 ¥28–38，美区 $7.99–9.99 | 参考同品类 indie 肉鸽定价带；首发 10% off |
| DLC/资料片 | 新角色 + 新武器族 + 新 Boss（每 6–9 个月一部） | 现有 SkillDef 数据驱动，扩内容成本低 |
| 装饰内购 | 角色皮肤（免费更新附带 1–2 款，DLC 含主题包） | 不影响数值，规避"氪金即强"口碑风险 |
| 广告变现 | **不建议** | 激励视频会打断单局节奏；且国内需额外广告 SDK 合规审查 |
| 抽卡/开箱 | **禁止** | 国内监管红线，海外社区口碑亦差 |

- 成就系统与 Steam 云存档：放在 M6（内容扩充）与 M7（上线冲刺）之间，作为社区运营抓手。
- 遥测（匿名）用于平衡调优，**不得**用于个性化推送；网络上报须在隐私政策更新 + 用户单独同意后开启。

## 四、海外发行（Steam）要点

1. **商店页**：需 5+ 截图（1280×720 以上）、1 支预告片、英文/中文双语描述；标签建议：Action Roguelite、Survival、Pixel Graphics、Local Coop/Online Coop、Singleplayer。
2. **配置要求**（目标）：Win10 64 位、4GB RAM、DX11、约 500MB——本工程体量远低于此，可作卖点。
3. **构建**：`StarPixel/构建 Windows (IL2CPP 正式包)` 生成 `Build/Windows/StarPixelRogue.exe`；Mac/Linux 后续按需扩展（Unity 一键切换目标）。
4. **试玩节/Demo**：以当前 M5 版本即可切 Demo（主菜单 + 单局循环已完整），是低成本获客手段。
5. **地区合规**：GDPR/CCPA 声明已在隐私政策覆盖；无内购则无家长同意流程压力。

## 五、上线前验收清单（必过）

- [ ] 合规门：全新安装 → 忠告 + 三协议可读 → 不同意退出、同意进入菜单；同意后重启不再弹
- [ ] 协议版本号递增（VersionInfo.ComplianceVersion）后，老用户重启重新弹门
- [ ] 青少年模式：开启 → 设置中可见提示；改系统时间跨天 → 计时重置（PlaytimeGuard）
- [ ] 时长限制：改本机时间把 playtime.json 的 seconds 调到 59.5 分钟 → 预警出现、到点强制回菜单
- [ ] 设置：三项音量实时生效、画质/全屏切换生效、重启游戏后保持
- [ ] 语言：中↔英切换，HUD/菜单/结算/设置全部跟随（联机大厅文本除外，见已知限制）
- [ ] 战绩：一局结束后纪录落盘、主菜单刷新、新纪录徽标正确
- [ ] 重开：连续 5 次「重新开始」无残留（HUD 画布/玩家/管理器不重复）
- [ ] 联机：房主/客户端双开（127.0.0.1）→ 击杀同步、升级选卡、掉线回大厅（README M4.5 清单）
- [ ] 构建：Mono 与 IL2CPP 均出包，版本号与 BuildInfo.json 一致，冷启动 10 秒内进菜单
- [ ] 法务：三份法律文本经律师审核，占位邮箱/主体信息替换为真实信息
